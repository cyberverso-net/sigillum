### Added

- `sigillum-testpki`, the unpublished program that will generate and check the test corpus, with stub subcommands `generate`, `tsa` and `verify`.
- The format of the test corpus manifest, `testdata/manifest.toml` (format version 1), documented in `testdata/README.md`, with the fixed validation time 2030-01-15T10:00:00Z, a digest per artefact and links between artefacts.

### Changed

- ADR-0013 states that an artefact counts as rejected only when DSS cannot parse it, a failed validation being recorded as an indication and a sub-indication.

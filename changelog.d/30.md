### Added

- `sigillum-testpki tsa`, which issues an RFC 3161 timestamp token for a digest at a given time and writes it to standard output in DER. It takes the digest algorithm (SHA-256, SHA-384 or SHA-512, by name or by object identifier in canonical dotted form, so an arc with leading zeros is refused), the digest in hexadecimal, the time in the form `YYYY-MM-DDTHH:MM:SSZ`, and the authority's PKCS#8 key and certificate. The token carries the ESS `signingCertificateV2` attribute and no `signingTime`, and its serial number is derived from the request, so that no clock is read and every token is reproducible.
- `sigillum-testpki generate timestamps`, which writes standalone timestamp tokens under `testdata/timestamps/` with the data they cover, and records each in the manifest: a valid token, one signed by a certificate without `id-kp-timeStamping`, one whose message imprint does not match, and one with a `genTime` after the validation time.
- The test object identifier `1.3.6.1.4.1.32473.1.2`, the policy of the test timestamping authority.

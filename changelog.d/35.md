### Added

- The `validate-certificate` mode of `tools/dss-oracle`, which validates a certificate with DSS at a fixed validation time, using only the trust anchors, certificates, CRLs and OCSP responses given on the command line. The first `--certificate` is the certificate to validate; the others are supplied for its chain. DSS applies its default certificate validation policy. The mode writes the DSS diagnostic data, detailed report and simple certificate report as XML, unchanged, and `summary.json` with the indication and sub-indication of the X.509 validation of the chain, the result that the simple certificate report gives the certificate itself, and the revocation status with the CRL or OCSP response that DSS used. An input that DSS cannot parse or use gives the result `rejected` with the parser message and exit code 0, with the input checks of `validate-timestamp`. The schema of `summary.json` is described in `tools/dss-oracle/README.md`.

### Fixed

- `tools/dss-oracle` rejects an OCSP response whose signature algorithm DSS does not support, instead of failing with exit code 1 when DSS reads the algorithm, in `validate-timestamp` as in `validate-certificate`.

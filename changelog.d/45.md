### Added

- Changelog fragments under `changelog.d/`, one per issue, compiled into the changelog when a release is prepared.

### Changed

- ADR-0012 states which values of the certificate policy inputs of RFC 5280, section 6.1.1, are supported.
- The security policy links directly to private vulnerability reporting.
- The development process includes a checklist for raising the minimum supported Rust version.
- The licence policy lists only the licences accepted so far under ADR-0003, without `Zlib`, and no longer warns about entries that no dependency uses yet.

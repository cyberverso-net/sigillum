### Fixed

- The `sign` mode of `tools/dss-oracle` reads the output of the timestamp program from temporary files instead of pipes, so that the result no longer depends on when the JVM notices that the program has ended. A program that exits without a token fails at once, even when a process it started keeps its output open, and a program that writes more than 1 MiB of output or 64 KiB of error output is stopped at its next check and fails.

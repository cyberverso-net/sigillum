### Added

- The `validate-document` mode of `tools/dss-oracle`, which validates the signatures of a CAdES, PAdES or JAdES document with DSS at a fixed validation time, using only the trust anchors, certificates, CRLs and OCSP responses given on the command line. The supplied certificates are candidates for the signing certificate of a signature that does not hold it. `--detached` gives the content of a detached signature, and `--policy aligned|default|<file>` the validation policy, as in the other validation modes: the aligned policy of ADR-0023 by default. The mode writes the DSS reports as XML, unchanged, and `summary.json` with, for each signature, the format and level that DSS detected, the indication, the sub-indication, the signing time that the signature claims and the best signature time. The top-level indication is given only for a document with exactly one signature. A document, policy file or other input that DSS cannot parse gives the result `rejected` with exit code 0. Before the validation, the mode makes the calls on the document on which DSS 6.5.1 has been observed to fail; the checks are not exhaustive, and a document on which DSS fails later ends the run with exit code 1. The schema of `summary.json` is described in `tools/dss-oracle/README.md`.
- Resource limits for every validation mode of `tools/dss-oracle`: DSS runs on a worker thread with a fixed stack of 64 MiB, within the heap of the JVM and a time limit set with `--timeout` (300 seconds by default). A run that exceeds one ends with the result `resource-limit`, the limit exceeded, the values of the limits and the garbage collectors of the JVM, and exit code 0.
- `summary.json` records the identity of the oracle in every mode: the versions of the tool and of DSS, and the PDF backend of DSS with the version of Apache PDFBox.

### Changed

- The format of `summary.json` of `tools/dss-oracle` is version 3: it adds the member `oracle` and the result `resource-limit`.
- `tools/dss-oracle` depends on `dss-cades`, `dss-cms-object`, `dss-pades`, `dss-pades-pdfbox` and `dss-jades` 6.5.1, which bring Apache PDFBox 3.0.8, jose4j 0.9.7 and json-sKema 0.32.0 with their dependencies. The licences are listed in its README.

### Fixed

- `sigillum-testpki` killed no process group on Ubuntu 24.04: the `kill` program of procps-ng 4.0.4 rejects a negative process group after `-s`, so the group of an `openssl` run of `verify --openssl`, and of the Java run of `generate signed`, survived the time limit. The signal is now given as `-KILL`.
- `sigillum-testpki` now kills the process group of a run whenever it stops the run, before it reaps the program. A run that writes more than its output limit while a process it started keeps its outputs open now ends at once with the output error, instead of at the time limit.

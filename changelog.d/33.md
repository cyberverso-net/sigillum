### Added

- `sigillum-testpki verify --dss` checks every certificate, CRL, OCSP response, timestamp token and signed document of the test corpus with DSS, through the `validate-certificate`, `validate-timestamp` and `validate-document` modes of `tools/dss-oracle`, and compares each result with the manifest. The DSS version of the tool must be the one that the manifest header names. The four artefacts of the divergence DIV-5 must give the result of DSS that it records.
- The workflow `fixtures-dss.yml` runs `verify --dss` on Linux without network for every pull request and every push to `main`.

### Changed

- `sigillum-testpki verify` without `--openssl` or `--dss` now runs both checks, where it was a usage error. An option of a check that does not run, such as `--openssl-program` with `--dss` alone, is a usage error.

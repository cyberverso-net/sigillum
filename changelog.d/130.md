### Added

- `sigillum-pki` provides the types that every format crate shares. `Context` carries the signing time and the validation time, supplied by the caller as `UnixTime`, the trust anchors, the certificates and revocation data the caller already has, the limits, and the choice to accept a lower level when the revocation status is unknown, which is off by default.
- `Limits` bounds the size of each kind of input, the nesting depth, the number of evidence rounds and requests, and the size of fetched responses. Each limit has a documented default and maximum, and a value above the maximum is refused when it is set.
- `Error` is the one error type of the library. It offers `kind()` with the categories `Malformed`, `LimitExceeded`, `NotSupported`, `InvalidInput`, `StateMismatch`, `SignatureMismatch`, `EvidenceRejected` and `EvidenceUnavailable`, a location where one applies (a byte offset, a JSON pointer or a PDF object), and a fixed message. It never carries input content.
